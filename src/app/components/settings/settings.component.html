Movimenti bancari

Carica l'export "Movimenti" (.xlsx) della banca: entrate e uscite vengono categorizzate in automatico. Puoi ricaricare export che si sovrappongono: i movimenti già presenti vengono saltati.

1

Archivia i dati attuali facoltativo

Salva tutti i movimenti in un file storico-spese-AAAA-MM-GG.json nella cartella degli export (vedi Gestione dati) e li cancella dall'app. Membri, categorie, regole e budget restano. Lo storico si può reimportare quando vuoi.

Come funziona l'importazione

  • Seleziona un file JSON esportato in precedenza
  • I movimenti del file si aggiungono a quelli esistenti
  • I movimenti già presenti (stesso id) vengono saltati
  • Le righe non valide vengono ignorate

Attenzione

La cancellazione dei dati è irreversibile. Esporta i dati prima di cancellarli.
